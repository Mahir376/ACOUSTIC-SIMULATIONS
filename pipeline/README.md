# LLM-driven acoustic scene generation

Pipeline for the bachelor's thesis *Large Language Model Driven Dynamic Acoustic Simulations*
(Tampere University). A large language model designs a small flat and writes a movement script for one
actor; the script is validated, rendered with simulated room acoustics, and labelled. The pipeline is
then used to measure how reliably the model produces valid layouts, trajectories and sound sequences.

## Stages

| Stage | Script | Input | Output |
|---|---|---|---|
| 1 Room generation | `main.py` | scenario text or a hand-drawn tile map | `spatial_map.json` |
| 2 Script generation | `action.py` | `spatial_map.json`, scenario text | `trajectory.json` |
| 3 Acoustic rendering | `pyroom.py` | both JSON files | `rirs/rir_bank.npz`, `rirs/room_acoustics.json` |
| 4 Audio synthesis | `audio.py` | `trajectory.json`, RIR bank, `SAMPLES/` | `scene_audio.wav`, `scene_labels.csv`, `scene_events.json` |

Support: `scene_common.py` (grid, coordinates, tables), `ctf_ltv_direct.py` (time-varying convolution
provided by the co-supervisor, used unmodified), `make_sources.py` (synthetic source signals),
`run_study.py` (capability study and resolution test), `prompt_study.py` (prompt comparison),
`validate_pipeline.py` (accuracy checks), `visualise_audio.py` and `acoustic_figures.py` (figures),
`maps/real/` (rooms traced from real floor plans).

## Setup

```
conda create -n acoustic-scene python=3.12
conda activate acoustic-scene
pip install -r requirements.txt
```

Stages 1 and 2 call Azure OpenAI. The credentials are read from the environment and never stored in
the repository:

```
set AZURE_OPENAI_ENDPOINT=https://<resource>.openai.azure.com/
set AZURE_OPENAI_API_KEY=<key>
set AZURE_OPENAI_DEPLOYMENT=<deployment name>
```

## One scene

```
python main.py --shape T-shaped
python action.py --scenario "The actor cooks at the kitchen counter, eats at the table, then watches TV on the sofa."
python pyroom.py --spacing 0.125
python audio.py
python validate_pipeline.py
python visualise_audio.py
python pyroom.py --spacing 0.125 --ray-tracing --out-dir rirs_rt
python acoustic_figures.py --compare rirs_rt/rir_bank.npz
```

Options: `main.py --references maps/real --rules --reasoning --no-examples --given-map <file>`;
`action.py --no-tile-list --plan-first --self-check --attempts 1`; `pyroom.py --spacing --ray-tracing`.

## Experiments

```
python run_study.py --runs 10                                   capability study (about 210 LLM calls)
python run_study.py --resolution                                RIR spacing against rendered level
python prompt_study.py layout --runs 10                         layout prompt comparison
python prompt_study.py trajectory --runs 5                      trajectory prompt comparison
python prompt_study.py prompts                                  exact prompt texts
```

All trajectory measures are taken on the first LLM answer, before repair. Results go to `study/` and
`prompt_study/` as CSV files plus every LLM answer as JSON; runs can be interrupted and resumed.

## Conventions

One tile is 0.5 m; grid coordinates are `[x, y]` with y downwards. In metres, `X = x * 0.5`,
`Y = (height - y) * 0.5`, z upwards. The microphone `M` is fixed at 1.2 m and its tile is not walkable;
the source is the actor at 1.5 m. Labels use the STARSS23 layout: 100 ms frames, class, azimuth
counter-clockwise from +X, elevation, distance in cm. Sample rate 24 kHz.

## Source signals

`SAMPLES/` holds synthetic source signals generated by `make_sources.py` (see `SAMPLES/SOURCES.md`).
They are dry by construction, so all spatial cues in the output come from the room simulation.
A dry recording with the same file name replaces a synthetic signal.

## Limits

One actor, one sound at a time, omnidirectional source and receiver, mono output. Furniture adds
absorption but is not geometry. The default image-source simulation stops at reflection order 6, so
the decay is truncated; `--ray-tracing` gives the full reverberation. Blending between neighbouring
impulse responses loses level at high frequencies at every practical spacing.
